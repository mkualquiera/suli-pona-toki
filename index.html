1. Introduction

suli pona toki is a dialect of toki pona inspired by Japanese sentence structure and Forth-like stack-based processing. Instead of using word order and context like regular toki pona, everything is expressed through suffix particles that you attach to words.

Think of it this way: instead of saying "mi lukin e tomo" (I see house), you say "misu tomomo lukinpa" (I-SUBJECT house-OBJECT see-VERB).

What Makes This Different

  • Particles do all the grammar work: No ambiguity about what's a subject vs. object
  • Preposition order and location is flexible: You can move things around for emphasis
  • Head-final structure: Modifiers come before what they modify
  • Subject-Object-Verb pattern: The verb comes last

Don't worry if this sounds complex! We'll build it up step by step, starting with the most basic particles.

2. Basic Particles

Every sentence in suli pona toki is built from three core particles that you attach as suffixes to words. Let's start with these fundamentals:

The Essential Three

Core Particle Suffixes
Subject Marker
jansu = "person (as subject)"
Add -su to mark who/what does the action
Object Marker
tomomo = "house (as object)"
Add -mo to mark who/what receives the action
Verb Marker
lukinpa = "see (as action)"
Add -pa to mark the action itself

Your First Sentence

Let's build a simple sentence step by step:

Building: "The person sees the house"
Step 1: Who does it?
jansu
person-SUBJECT
Step 2: What receives it?
jansu tomomo
person-SUBJECT house-OBJECT
Step 3: What action happens?
jansu tomomo lukinpa.
person-SUBJECT house-OBJECT see-VERB = "The person sees the house."
Practice Exercise 1
How would you write "I eat food" using particles?
Answer: misu mokumo mokupa.
Explanation: mi-SUBJECT moku-OBJECT moku-VERB (I-SUBJECT food-OBJECT eat-VERB)

Word Order Rules

The word order is actually quite structured: Subject → Object(s) → Verb. This is because each object applies to the next verb, allowing for complex sentences:

Word Order Pattern
Simple (SOV)
jansu tomomo lukinpa.
Subject-Object-Verb: "The person sees the house"
Multiple Objects (SOOV)
jansu tomomo lupamo lukinpa.
"The person sees the house and the door"
Multiple Verbs (SOVOV)
jansu tomomo lukinpa lupamo openpa.
"The person sees the house and opens the door"

3. Prepositions

Now that you know the basic sentence structure, let's add detail with prepositions. These show relationships like location, direction, and method. The key insight: prepositions can attach to any grammatical element and go anywhere in the sentence.

The Six Preposition Suffixes

Preposition Particles
Direction/Toward
tomota = "to/toward the house"
Add -ta (from "tawa")
Origin/From
tomona = "from the house"
Add -na (from "tan")
Location/At
tomolo = "at the house"
Add -lo (from "lon")
Using/With
iloki = "using/with a tool"
Add -ki (from "kepeken")
Manner/Like
janwe = "like a person"
Add -we (manner/similarity)
Metacommentary
mi lonlu = "honestly" (lit: "from my truth")
Add -lu (speaker's perspective)

Prepositions Can Attach Anywhere

Unlike the strict S-O-V order, prepositions can move around to attach to different parts of the sentence. This creates different meanings:

Flexible Preposition Placement
Prepositional Subject
tomolo jansu lekomo tawapa.
"The person at the house moves the box."
Prepositional Verb
jansu lekomo tomolo tawapa.
"The person moves the box at the house."
Prepositional Object
jansu tomolo lekomo tawapa.
"The person moves the box that's at the house."
Practice Exercise 2
How would you say "I walk to the store using my feet"?
Answer: misu esunta noka miki tawapa.
Explanation: I-SUBJECT to-store my-feet-WITH walk-VERB

4. Advanced Particles

Now let's learn about particles that connect ideas and add logical relationships.

Logical Connectors

Union and Alternative Particles
Union (and)
miun sinasu = "you and I"
Add -un to connect things with "and"
Alternative (or)
minu sina = "me or you"
Add -nu to show alternatives with "or"

Context and Apposition

Sentence Connectors
Context Setting
tenpo pinila, jansu tawapa.
"In the past, the person went." (-la sets context)
Explanation
jansu ponapa: ni ponapa.
"The person is good: this is good." (colon for explanation)
Practice Exercise 3
How would you say "When it's dark, you or I will sleep"?
Answer: pimejala, minu sinasu lapepa.
Explanation: dark-CONTEXT, me-OR you-SUBJECT sleep-VERB

5. Modifier Structure

suli pona toki uses a head-final structure where modifiers come before what they modify. We also have special particles "pi" and "no" to group complex ideas.

Simple Modification

Basic Modifier Order
Single Modifier
pona jansu = "good person (as subject)"
Modifier comes before the word it modifies
Multiple Modifiers
suli pona jansu = "big good person"
All modifiers come before, closest to the head is most important

Property Grouping with "pi"

The word "pi" creates nested semantic units - like nested parentheses. Each "pi" creates a new grouping level, building complex hierarchical structures:

Nested "pi" Structure
Latin Script
nasa telo pi ike jan pi suli telosu.
Sitelen Rendering

nasa telo ike jan suli telo

((crazy water) bad person) big liquid = "The person who deals with crazy water and bad people, who is associated with big liquids"

Possessive Restructuring with "no"

The word "no" is different from "pi" - it creates possessive/attributive relationships that restructure the semantic hierarchy, like different types of parentheses:

"pi" vs "no" Comparison
With "pi" (nested grouping)
nasa telo pi ike jan pi suli telosu.

nasa telo ike jan suli telo

Nested properties: ((crazy water) bad person) big liquid
With "no" (possessive restructuring)
nasa telo pi ike jan no suli tomosu.

nasa telo ike jan suli tomo

Possessive structure: (crazy water) of (bad person's big house)

Notice how the sitelen telo rendering makes this crystal clear: "pi" creates nested property boxes, while "no" creates glue structures showing possession/attribution relationships.

6. The "an-" Prefix

The "an-" prefix creates true opposites - not just negation, but actual opposite concepts. This is different from saying something is "not good" (ala pona) versus saying it's "bad" (anpona).

Common Opposites
Good → Bad
pona → anpona
good → bad (not just "not good")
Big → Small
suli → ansuli
big → small
Light → Dark
suno → ansuno
light → dark
Practice Exercise 4
What's the difference between "ala pona" and "anpona"?
Answer: "ala pona" = "not good" (neutral, could be mediocre)
"anpona" = "bad" (actively negative, the opposite of good)

7. Writing System (sitelen telo)

suli pona toki uses sitelen telo, a logographic writing system for toki pona created by olb. The system combines word glyphs with semantic indicators that show grammatical relationships visually.

Font and Resources

The recommended font is sitelen telo, available from sona.pona.la/wiki/sitelen_telo. This font includes proper ligature support which is essential for correct rendering.

How Particles Appear in sitelen telo

In sitelen telo, the particles we've learned show up as small markers. Here's how Latin script maps to sitelen rendering:

Particle Mapping
Subject: jansu
jan
Content + li marker
Verb: ponapa
pona
Content + pali marker
Object: tomomo
Content + e marker
Direction: tomota
tomo
Content + tawa marker
Negation: anpona
pona
ala marker + content

Note: Proper ligature support is crucial for sitelen telo rendering. If the text appears broken or disconnected, ensure your browser supports OpenType ligatures and that the correct sitelen telo font is installed.
